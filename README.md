# Portfolio site

A minimal self-promotion / portfolio site boilerplate: React + Vite, no router, one page with a hero, about, work, and contact section.

## Customize

- `src/App.jsx` — edit the `name`, `role`, `tagline`, `email`, `socials`, `skills`, and `projects` values at the top of the file.
- `index.html` — update the `<title>` and meta description.
- `public/favicon.svg` — swap in your own mark or initials.
- `src/App.css` / `src/index.css` — theme colors live as CSS variables in `index.css` (`--accent`, `--bg`, `--text`, etc.) and automatically switch for dark mode via `prefers-color-scheme`.

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
